# JobTrack — Job Application Tracker

JobTrack is a project I'm building to organize and track job applications.

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Postman for API testing

## Features

- Manage job applications
- Store company information
- Associate job applications with companies
- Track application details and status

## What I'm Learning

- Building REST APIs using Spring Boot
- Connecting Java applications to MySQL
- Working with entities and database relationships
- Testing APIs using Postman

## Project Status

Currently under development. I'm adding features, fixing bugs, and improving the application step by step.

## Future Improvements

- Search and filter job applications
- Pagination and sorting
- Input validation and error handling
- Automated testing
